# Mines Simulator — Android project

Это учебный симулятор случайного поля 5×5. Он не подключается к RubUP и не предсказывает серверные результаты сторонних игр.

## Сборка APK с телефона через GitHub

1. На телефоне открой github.com и войди в аккаунт.
2. Создай новый репозиторий, например `mines-simulator`. Можно сделать его Private.
3. Распакуй архив проекта на телефоне.
4. В репозитории нажми **Add file → Upload files** и загрузи содержимое папки проекта, сохранив структуру папок (`app`, `.github` и файлы Gradle).
5. Нажми **Commit changes**.
6. Открой вкладку **Actions** в репозитории.
7. Выбери **Build Android APK** → **Run workflow** (если сборка не запустилась автоматически после commit).
8. Когда задача завершится зелёной галочкой, открой её и найди раздел **Artifacts**.
9. Скачай `mines-simulator-debug-apk`, распакуй скачанный ZIP и установи `app-debug.apk`.

При первой установке Android может попросить разрешить установку приложения из используемого браузера или файлового менеджера. Разрешай её только если сам собрал проект и доверяешь его содержимому.

## Что делает приложение

- Поле 5×5.
- Настройка числа мин от 1 до 24.
- Случайная генерация мин в каждом новом раунде.
- Расчёт теоретической вероятности безопасной клетки среди ещё не открытых клеток в текущей симуляции.

## Технические детали

- Минимальная версия Android: API 23.
- Сборка: Gradle + Android Gradle Plugin.
- APK: debug-вариант, не подписанный для публикации в Google Play.
